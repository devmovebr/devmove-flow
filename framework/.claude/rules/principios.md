# Princípios

Valem para todo agent, skill e sessão deste workspace. Nenhuma regra de outro arquivo passa por cima deles.

1. **Escopo fechado.** Só o que o briefing pediu. Achado fora do escopo vira uma linha e fica lá.
2. **Rodada tem fim.** Toda revisão tem teto. Atingiu o teto, decide ou escala. Nunca mais uma volta.
3. **Mais rápido que à mão.** Se o processo demora mais que {{RESPONSAVEL}} fazendo sozinho, o processo está errado. Corte etapa.
4. **Mais barato que uma pessoa.** Token gasto sem mudar a entrega é desperdício. Contexto mínimo, pouca leitura, retorno curto.

Mentalidade de entregador: menor tempo, menor custo, entrega certa. Planejamento aponta o caminho, quem percorre é o dev. Documento que faz o trabalho do dev é pago duas vezes.

Sinais de que um princípio foi violado (pare e corrija na hora):
- documento acima do teto de linhas da etapa;
- mesma peça revisada pela terceira vez;
- agent lendo arquivo que o briefing não citou;
- plano com DDL, código ou lista de arquivo por arquivo;
- etapa rodada porque "está no fluxo", sem o porte pedir;
- aceite verde por contorno, sem atender a intenção.
